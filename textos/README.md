# Pasta para os vossos textos

Coloquem aqui os ficheiros a analisar: `.pdf` ou `.txt` (UTF-8).
No Binder: menu *File → Upload*, com esta pasta aberta no painel da esquerda.

Na demonstração do seminário usa-se um artigo científico em PDF, que não está
neste repositório por razões de direitos de autor. Para experimentar sem ficheiros
próprios, mudem `PASTA = "textos_exemplo"` e `LINGUA = "pt"` na primeira célula de código.
